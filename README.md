# Frontline Command

A small turn-based military strategy game built for GitHub Pages.

## How to play

- Click one of your blue units.
- Choose **Move**, **Attack**, or **Wait**.
- Capture the tile marked with a gold star.
- Hold the objective for 3 turns to win.
- You also win by eliminating all enemy units.

## Units

- Infantry — balanced, short-range.
- Tank — strong direct attacker.
- Artillery — attacks from 2–3 tiles away.
- Recon — fastest unit on the map.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

Upload these files to a GitHub repository, then enable GitHub Pages for the repository's main branch.
